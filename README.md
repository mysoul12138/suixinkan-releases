# 随心看（Suixinkan）

Android TV / 手机端的影视聚合客户端，基于 TVBox 2024 二次开发。

**这个仓库只用于发布**：安装包、更新清单。源码不在本仓库。

## 下载

最新版本在 [Releases](../../releases/latest) 页面。

| 文件 | 说明 |
| --- | --- |
| `Suixinkan_2024_<版本>.apk` | 安装包（armeabi-v7a，Android 5.0+） |
| `Suixinkan_2024_<版本>.apk.sha256` | 安装包校验值 |
| `update.json` | 应用内自更新清单（签名信封，请勿手改） |

电视和手机用同一个包，应用会按屏幕方向自动切换布局。

## 应用内更新

客户端会依次尝试多个清单地址，取到签名有效的清单后按版本号判断是否需要更新；
下载完成后校验 SHA-256，再交给系统安装器。清单由离线私钥签名，篡改会导致校验失败。

电视首次安装更新时，部分定制系统会拦掉静默安装，需要遥控器点一次「安装」。
